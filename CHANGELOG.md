Potion HUD now runs on Minecraft 26.3. The four display modes remain available both on their own and through Eymistaken's HUD 1.2.3. This release targets 26.3 only; use the previous release for Minecraft 26.2.

The keybind category now displays **Eymistaken's Potion HUD** instead of a translation key. Existing configuration keys and the HUD module identity are unchanged so saved settings and layouts can continue to load.
